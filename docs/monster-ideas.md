# 天空囚笼 · 怪物与 Boss 创意记录

> 状态：创意阶段，**只是记录，没有实现**。
> 依据：分支 `fog-and-additional-lights`（截至 2026-10-12 的提交）里 AI 脚本的头部注释，加上设计讨论。
> 没有读过单位定义里的具体数值，也没有看过场景内容。标 **（待确认）** 的是推测。

## 一、设计原则

1. **读得懂**：每种怪的威胁都要有明确的预警（沿用地面圆环、预警线、空气扭曲这套视觉语言）。
2. **不依赖配对识别**：机制不能要求玩家分辨"谁和谁是一对"。同种怪一多就变成连连看。
   - 已否决：双生体、必须同时击杀的同步怪。
3. **成群也成立**：机制在多只同时出现时仍然可玩。
4. **复用已有系统**：优先利用属性异常、失衡条、弱点/暴击词条、撤离压力、光照与视野。
5. **前期怪可以"绕行"**：织面者定位为前期玩家绕着走的怪，后期靠成长变得可打。

## 二、已实现的怪物（分支里有单位定义和 AI 脚本）

| 名称 | 机制摘要 |
|---|---|
| 咏唱者 α/β/γ/δ | 站桩；地面三条预警线，错开时间沿 X 方向发三发弹；三路在深度（Z）上并排，靠换深度躲。四个变体的差异（待确认） |
| 织面者 | 休眠，被惊动或受伤才醒；出招前绕圈试探；直线冲刺 / 蜘蛛式跳扑；近战时有概率真闪避（有无敌帧）；追击走 Z 字；远距离加速；被拉离出生点太远则放弃回家并重置休眠 |
| 灰炉 | 固定瘴气装置；半径内每秒累积"灰色损失"，满了即死；能被打死，但按比例回血（集火检测）；瘴气半径比枪射程大 |
| 守卫者 | 带耐久的盾；物理大幅减免，属性伤害不减免且更伤盾；盾只挡正面，转身有延迟，绕背无视盾；盾不修复；有"护卫"特质，站在咏唱者/灰炉/颂赞者与玩家之间 |
| 颂赞者 | 支援；自己不攻击、很脆；牵线最多 3 只同伴，被连者减伤 85% 并狂暴（攻击↑防御↓移速↑行动速度↑）；颂赞者死则连线断；不连灰炉、守卫者、其他颂赞者；站位躲玩家，贴近时短后撤 |
| 怪人（Mirage） | 光学迷彩伏击；潜行接近，可能绕背；攻击不现形，前摇只有空气扭曲；背刺 ×1.5，迷彩偷袭 ×1.3；偷袭附带电磁累积；谨慎后退重新隐身，迷彩冲刺换位；失衡时被打断硬直 |
| 震碎者（Boss） | 四足慢走，四条腿轮流落地，每脚扩出环形冲击波（跳起或闪避可躲）；落脚砸人大伤害加击退；腿有独立血量，打断后永久不修复；规划中：场内随机弹幕、阶段 |

### 当前最凶的组合
2 只织面者 + 1 只颂赞者：织面者本身机动性强，被连线后再叠 85% 减伤和狂暴，防御↓的代价被减伤盖过去。
可调方向：失衡打断连线、缩短狂暴残留、按连线数量递减减伤、连线可视化、延长颂赞者后撤冷却。
**态度：织面者定位就是前期绕行怪，这个组合可以保留为"看到就绕开"的精英遭遇。**

## 六、Boss 草案：卓帕卡布拉（Chupacabra）

### 定位
- 夜版限定，可在任何地图出现，一套资源复用。
- 与震碎者相反：震碎者是慢速地面节奏 Boss，卓帕卡布拉是高速跳跃突袭 Boss。

### 招式（数值均未定）

| 招式 | 说明 | 躲法 / 破绽 |
|---|---|---|
| 跳跃接近 | 一路弹跳逼近，落点有地面预警圈 | 看落点预警，换位；落地硬直 |
| 地刺（向前蔓延） | 沿面朝方向一排地刺依次破土，出刺前有预警，升起后停留 1–2 秒成为临时地形 | 侧向换深度；刺高，不能靠跳 |
| 拖拽 | 吐出舌头 / 钩爪 / 触手，命中后把玩家拉向它；前摇明显 | 打断前摇、闪避、掩体断线 |
| 吸血 | 拖到身边后持续扣玩家血并给自己回血 | 失衡可打断；吸血期间可被反杀 |

### 设计要点
- 吸血是**可被打断的持续伤害**，对应哪种资源待定（LP / 最大生命 / 灰色损失）。可考虑吸血期间 LP 不回复。
- Boss 回血转为护盾而不是直接加血，避免越打越高。
- 拖拽冷却、只能命中一次；被拖到后给短暂保护，避免锁死。
- 拖拽路径穿过地刺时不应对玩家造成伤害，否则变成必然惩罚。
- 地刺和拖拽不要在同一个连招里连续出现。
- 可破坏部位：舌头 / 触手，类似震碎者的腿；打断后拖拽失效或变弱。
- 失衡时，进行中的地刺保留，只停止后续新刺，避免失衡变成万能按钮。

### 阶段
- 第一阶段：单排地刺，节奏慢，预警长。
- 第二阶段（血量低于一半）：两排或扇形，间隔缩短，部分地刺附带腐蚀异常。
- 狂暴阶段：地刺出现在 Boss 周围，吸血速度翻倍但被打断后硬直更长，形成"想打断就得冒险"的张力。

### 两种出场配置（共用同一套资源）

| | 固定型（巢穴） | 巡游型（夜间猎手） |
|---|---|---|
| 出现方式 | 指定地点，走近触发 | 夜版开局后在地图里游荡 |
| 定位 | 正面 Boss 战，完整血条 | 天灾，可战可躲 |
| 活动范围 | 巢穴范围（沿用 leash） | 全图，需要巡游路径 |
| 奖励 | 稀有掉落 | 较少，鼓励"躲" |

巡游型状态循环：游荡 → 潜行搜寻（可被噪音吸引）→ 突袭 → 进食 / 撤退（给玩家喘息和撤离窗口）→ 脱战回到游荡。
同一局不要同时出现两种配置。
撤退后是否回血、回多快，待定（倾向很慢，让打得狠的玩家有奖励）。

### 技术依赖（待确认）
1. 敌方大幅跳跃需要高度参与碰撞和命中判定（飞行怪同样需要，可一起解决）。
2. 拖拽需要对玩家的外力位移，走 `UnitActionController` 的移动通道；需确认被拖时能否闪避或打断。
3. 巡游型需要全图巡游路径；现有 `SkyPrisonEnemyLeash` 是按出生点限制的。
4. 夜版判断：`SkyPrisonRaidRunContext.Night`（出发时由选关界面写入，已被战利品、小地图视野、玩家视野使用）。
5. Boss 血条可复用 `SkyPrisonBossHealthBar`。

## 七、可能的实现优先级（建议）

- 成本低、玩法收益高：属性吸收怪、拾荒怪、弱点游走怪（属性异常、撤离机制、弱点词条都已就位）。
- 需要新系统：飞行怪（高度）、噪音怪（听觉）、趋光 / 灭灯怪（光照感知）、卓帕卡布拉（高度 + 强制位移 + 巡游）。
- 后期：巢穴怪、蔓延怪。
