# 天空囚笼 · 修改清单（2026-10-13）

> 目标：动作 + 轻度搜打撤。先增加局内紧张感，减少"数值让游戏变简单"的倾向，多做功能性的东西。
> 依据：分支 `fog-and-additional-lights`（截至 2026-10-12 的提交）的代码和数据。文件路径都相对于 `Assets/_Project/`。
> 设计理由和讨论过程见 `docs/monster-ideas.md`。

## 设计支柱（改任何东西前先对照）

1. **每一局都有生命危险**：怪物始终致命，成长让你更有办法，但不会让你安全。
2. **贪还是撤**：玩家一直在"再搜一点"和"现在走"之间做选择。
3. **功能胜过数值**：新东西要改变打法，而不只是让数字变大。

## 第一批：紧张感（先做，做完就试玩）

### 1. 怪物血量下调、枪伤害上调

- [ ] **怪物血量**：改各单位定义 `parameterValues` 里的 `maxHp`。
  目录：`Data/Definitions/Custom/Units/Memento/`

  | 文件 | 现在 | 改为（起点，需实测） |

  | `UD_Enemy_TestMob_01` | 180 | 180（不动，作为基准） |
  | `UD_Enemy_Mirage` | 1,200 | ~500 |
  | `UD_Enemy_Chanter` | 1,800 | ~400 |
  | `UD_Enemy_CasterAlpha` / `Beta` / `Gamma` | 2,000 | ~600 |
  | `UD_Enemy_Guardian` | 2,000 | ~700（盾的耐久另调） |
  | `UD_Enemy_FaceWeaver` | 5,500 | ~1,300 |
  | `UD_Enemy_CasterDelta` | 12,000 | ~1,500 |
  | `UD_Enemy_GrayFurnace` | 10,000 | ~2,000 |
  | `UD_Boss_Shatterer` | 18,000 | ~6,000（腿的血量同比例下调） |

  目标（基础装备、没有 AFP）：普通怪 8–15 下，精英 20–30 下，Boss 2–3 分钟。
- [ ] **灰炉回血**：`Scripts/Core/Logic/Combat/SkyPrisonGrayFurnace.cs` 的 `regenFractionPerSecond`（现在 0.025，即每秒 2.5% 最大生命）。血量下调后按比例确认，仍要保持"前期火力压不住、但集火能打掉"。
- [ ] **守卫者盾耐久**：`SkyPrisonGuardianShield.cs` 的 `shieldDurability`，随血量一起下调。
- [ ] **震碎者腿血量**：`SkyPrisonShattererLeg.cs`，同比例下调。
- [ ] **枪伤害**：`京极五式军铳`（`Data/Items/ID_NewItem 1_Copy.asset`）攻击现在是 9，玩家基础攻击 5，合计 14；弹匣 12 发。
  目标：一个弹匣大约打死一只普通怪，即每发 40–50 左右。改武器的 `atk`，或者改 `SK_GunAttack2` 的 `damageMultiplier`（现在 1）。
- [ ] **怪物伤害不动**，但确认这些一击秒杀招式的前摇足够清楚：
  - 织面者冲刺（`SK_FaceWeaver_Dash`，倍率 4）、跳扑（`SK_FaceWeaver_Pounce`，倍率 6）
  - 怪人偷袭（`SkyPrisonMirageAI.cs` 的 `backstabMultiplier` 1.5、`ambushMultiplier` 1.3）

  参考公式：伤害 = 攻击 × 技能倍率 × 暴击 × (±10%) × 100/(100+防御) × (1−抗性)，属性伤害另算。

### 2. 灰雾侵蚀（局内时间压力）

- [ ] 新增一个局内计时组件，进本时开始，出本时停止（可以订阅 `AFPRuntime` 的局开始 / 结束事件）。
- [ ] 三个阶段（百分比是一局正常时长的比例，先测出正常时长再定）：
  - 安全期（0%–约 60%）：没有灰雾。
  - 预警期（约 60%–70%）：天色变暗、远处出现灰雾、广播或音效提示，**不扣**。
  - 侵蚀期（约 70% 之后）：调用 `SkyPrisonGrayLoss.EnsureOn(player)` 持续累积灰色损失，速率逐步加快。
- [ ] 撤离终端附近是安全区，不累积灰色。
- [ ] HUD 不显示精确倒计时，只显示阶段（比如一个从清到灰的图标）。屏幕颗粒效果 `SkyPrisonGrayLossScreenGrain` 已经会随灰色损失加重，直接利用。
- [ ] 夜版（`SkyPrisonRaidRunContext.Night`）安全期更短或侵蚀更快。

### 3. 撤离要有过程

- [ ] `Scripts/Core/Interaction/ExtractionTerminal.cs`：现在是"按 E → 确认 → 立刻结算"。改成：
  - 按下后需要坚守一段时间（起点 10–20 秒），期间发出噪音、吸引附近的怪物；
  - 坚守期间离开范围或死亡则中断；
  - 撤离终端附近是灰雾安全区。
- [ ] 每张地图 2–4 个撤离点，分布在不同方向；可以各有条件（钥匙、启动设备、限时开放），先做一种就够。

### 4. 箱子里也能拿到 AFP

- [ ] 现在 AFP 只来自击杀（`AFPRuntime.cs` 里按单位定义的 `afpYield`）和研修的"消耗品回收"小加成。
- [ ] 开箱结算时调用 `AFPRuntime.Instance.AddAFP(...)`。箱子定义里加一个 AFP 数量字段。
- [ ] 比例：击杀仍是主要来源，箱子约占三分之一。

### 5. 复活道具：无论带多少个，每局只能用一次

- [ ] `PlayerDeathDecisionController`：加一个"本局已复活"标记，进本时清零（订阅局开始事件）；已复活过则不再弹出复活选项，直接进入死亡结算。
- [ ] 可选：复活后加代价（血量很低、LP 清空，或吃掉一截最大生命），复活保护（`PlayerReviveProtection`）时间缩短到只够脱离危险。
- [ ] 复活道具（现在是 `临时补救模组`，`Data/Items/ID_NewItem.asset`，`isReviveItem = 1`）只能局外购买或制作，局内不掉落。

### 6. 回复道具要有读条

- [ ] 确认急救药物、罐头、压缩饼干等回复品使用时有没有读条时间。
- [ ] 没有的话加上：使用需要读条，受击会被打断。"什么时候回血"本身要是一个有风险的决策。

### 第一批做完后：试玩

找人玩一局（只用一张地图也行），观察：
- 快撤离时，玩家会不会变得小心（走慢、绕路、不想打架）；
- 撤离成功时，有没有松一口气；
- 死了之后想不想马上再来一局；
- 一局多长（目标 12–18 分钟）。

## 第二批：成长系统

### 7. AFP 改成按档选能力

- [ ] `Scripts/Core/Runtime/Raid/SkyPrisonAfpUpgrades.cs`：把"每级 +0.5%、最多 20 级 / 99 级"改成 3–4 档，每档一个看得见的变化。
  - 现状：抗性和攻击强化 `perLevel = 0.5f`；追加生命 `perLevel = 4`；全局涨价 `Inflation = 1.06`；开局 `BaseStartingAFP = 300`。
  - 保留全局涨价（偏科有代价）。
  - 数值还在，只是每一步更大，总上限维持"不抢装备的位置"（比如抗性最高仍是 10%，分 3 档）。
- [ ] `Scripts/Core/Runtime/Raid/SkyPrisonAfpAbilityTable.cs`：档位改成购买单位，每档一句效果。
- [ ] 研修只决定"这个能力会不会出现"，不再每一档都要点一个节点（现在是 `前缀_档位` 每档一个节点）。
- [ ] 固定菜单，不做随机三选一。
- [ ] 增加"零钱出口"：AFP 不够买下一档时，可以买回复、弹药、一次性护盾这类消耗品。
- [ ] 原则：局内变强的速度要慢于危险上升的速度；判断一个能力好不好，看"买了之后会不会改变打法"。

### 8. 功能性模组

- [ ] 模组效果以改变打法为主：消音器（降低开枪噪音，可接装备上已有的噪音倍率字段）、属性弹匣、弱点瞄具、重型枪管等。每个模组都要有代价（伤害、射速、负重等）。
- [ ] 模组鉴定改为撤离成功后自动鉴定（现在要付费鉴定，`ItemModExtension.identificationCost`）。

### 9. 武器强化

- [ ] 保留白值提升；按地图分档；设上限；可在 +3、+6 等节点解锁模组槽或特殊性能。
- [ ] 每个强化档位只认对应稀有度的素材（低一级素材贡献很少或无效）。20 只是格子上限，不需要放满。
- [ ] 每个素材按"品级 × 相性"提供成功率，放进去的加起来就是本次成功率；相性好的高级素材几个就能到 100%。
- [ ] 相性对每类武器隐藏，第一次放进强化即揭示，永久记录进图鉴；素材描述给模糊线索。
- [ ] 保底：失败时把这次的成功率存进保底槽，满 100% 下次必成（正常投入约 5 次必成）。防止用一个杂鱼素材刷保底。保底槽按武器、按等级记录，成功后清零，退出游戏不清零。
- [ ] 失败只扣素材，不掉级。界面显示本次成功率和保底槽。

### 10. 武器制作

- [ ] 制作是武器换代的主要途径（强化到上限后做更高阶的基底）。
- [ ] 来源分工：制作给武器基底；副本掉落给模组、素材、偶尔的稀有武器；商店只卖弹药、消耗品和最低一档装备。

### 11. 补上防具

- [ ] 现在仓库里没有任何防具，玩家只有基础血量 100、防御 10。防具是"局外决定能不能进更难地图"的主要手段之一。

## 地图与时长参考

- 一局 12–18 分钟（夜版 10–15 分钟）。
- 不打怪横穿全图约 2–3 分钟；一局能探索约一半到六成。
- 两次遭遇或决策的间隔 30 秒到 1 分钟。
- 任何位置离最近的撤离点不超过 1.5–2 分钟。
- 撤离点 2–4 个，AFP 购买区 2–3 个。
- 做环形路线，不做死胡同；高价值区放在深处或危险旁边；留出安静区。
